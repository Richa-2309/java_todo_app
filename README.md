# Java Todo App

A simple **Todo application built with Java and Spring Boot**. This project demonstrates how to build a basic CRUD-style backend with features for managing todo items.

## Features

* Add a new todo
* Delete a todo
* Manage todo data using SQL
* REST API built with Spring Boot

## Tech Stack

* **Java**
* **Spring Boot**
* **SQL**

## Project Overview

This project is built to practice backend development with **Java Spring Boot** and database integration. It provides a simple foundation for creating and managing todo items through APIs.
